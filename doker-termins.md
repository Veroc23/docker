# Ключевые понятия Doker'a

| Понятия | Описание | Аналогия |
| --- | --- | --- |
| Образ (image)| Неизменяемый шаблон: файловая система + команда запуска | Установочный фаил |
| Контейнер | Запущенный экземпляр образа | Запущенная програма (приложение) |
| Реестр (registry) | Хранилище образов (например, Doker Hub) | Магазин приложений |
| Dokerfile | Фаил с описанием сборки образа | Руководство по установки с приложения|
